# Asset OS — Screen Implementation Matrix

**Baseline:** 60 screens, six product phases of 10 screens each. Phase 0 is foundation only.

| Phase | Screen IDs | Feature area | Current status |
| --- | --- | --- | --- |
| 0 | Foundation only | App skeleton, layout, tokens, routing, demo dashboard, CI/Pages | In progress until verified |
| 1 | 01–10 | Asset Command Center and registry | Planned |
| 2 | 11–20 | Acquisition, ownership and lifecycle | Planned |
| 3 | 21–30 | Valuation, financing and economics | Planned |
| 4 | 31–40 | Maintenance, insurance and utilization | Planned |
| 5 | 41–50 | Portfolio, intelligence and risk | Planned |
| 6 | 51–60 | Kernel integration and administration | Planned |
| 7 | All | Cross-screen experience and visual certification | Planned |

The dashboard in Phase 0 is **a working design foundation preview**, not the completed Phase 1 screen.
Every future screen must have an implemented route, responsive layout, complete interactions,
test coverage and a documented connection to the canonical AOS-000 to AOS-140 requirements.
Do not count a placeholder, fake backend action, or screen title as implementation.
